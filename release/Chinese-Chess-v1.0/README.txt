中国象棋 - Chinese Chess v1.0
============================

运行方式：
  ./chinese-chess          # 开始游戏
  ./chinese-chess --mode=endgame  # 残局挑战
  ./chinese-chess --no-sound  # 禁用音效

系统要求：
  - Linux (x86_64)
  - 显卡支持 OpenGL/X11

功能特性：
  - 四级 AI 难度：初级、中级、高级、终极高手
  - 12 个经典残局挑战
  - 计时系统（每方 60 秒）
  - 音效支持
  - 美观的棋盘界面

安装：
  chmod +x chinese-chess
  ./chinese-chess

卸载：
  rm -rf ~/.local/share/chinese-chess
  rm -f ~/.local/share/applications/chinese-chess.desktop
