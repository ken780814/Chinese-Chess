- DirectX 9.0c 或更高

- Windows 10/11 (64-bit)

## 下载 / Download

**V2.0 版本**: [下载 Windows 版本](https://github.com/ken780814/Chinese-Chess/releases/tag/v2.0)

## 安装方式 / Installation

### 方式一：直接运行 / Method 1: Run Directly

1. 下载 `Chinese-Chess-v2.0-windows-x64.tar.gz`
2. 解压文件
3. 双击 `chinese-chess.exe` 启动游戏

### 方式二：使用批处理 / Method 2: Use Batch File

```cmd
chinese-chess.exe --mode=endgame
```

## 运行参数 / Parameters

| 参数 | 说明 |
|------|------|
| `--mode=endgame` | 进入残局挑战模式 |
| `--no-sound` | 关闭音效 |
| `--help` | 显示帮助 |
